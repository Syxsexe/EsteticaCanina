# Imágenes

Deja aquí el logotipo definitivo de Perro Look con el nombre `logo.png`
(o `logo.svg` si prefieres vector, cambiando `BrandLogo.assetPath`).

La carpeta entera ya está declarada en `pubspec.yaml`, así que basta con
copiar el archivo y correr `flutter pub get`. Mientras no exista, `BrandLogo`
dibuja el lockup tipográfico y la app funciona igual.
